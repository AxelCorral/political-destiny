# Couverture des questions produit — Phase 2

Statuts : `COVERED` (mesurable proprement, avec le bon dénominateur, sans proxy ambigu),
`PARTIAL` (donnée captée mais incomplètement exploitée, ou mesurable seulement sous condition),
`NOT COVERED` (donnée non disponible aujourd'hui). Un proxy approximatif n'est jamais compté
comme `COVERED`.

## Usage

| Question                        | Source                                             | Vue/KPI                                                  | Statut    | Limite                                                                                               |
| ------------------------------- | -------------------------------------------------- | -------------------------------------------------------- | --------- | ---------------------------------------------------------------------------------------------------- |
| Runs commencés / terminés       | `analytics_runs.started_at`/`completed_at`         | `fn_overview_summary` → Overview                         | `COVERED` | —                                                                                                    |
| Navigateurs anonymes récurrents | `analytics_runs.anonymous_user_id`                 | `replay_behavior`/`fn_replay_behavior` → Rétention       | `COVERED` | `anonymous_user_id` = navigateur, pas une personne (voir PRIVACY.md)                                 |
| Runs par navigateur             | idem                                               | `fn_overview_summary.runs_per_browser` → Overview        | `COVERED` | Moyenne globale ; pas de distribution par navigateur affichée                                        |
| Durée de campagne               | `completed_at - started_at`                        | `fn_overview_summary.median_duration_seconds` → Overview | `COVERED` | Médiane uniquement sur runs terminés — une durée d'un run en cours n'a pas de sens                   |
| Runs devenus inactifs           | `analytics_run_status.status = 'stale_incomplete'` | `fn_overview_summary.runs_stale` → Overview              | `COVERED` | Seuil configurable (`analytics_settings.stale_run_hours`) — jamais présenté comme un abandon certain |

## Notes de méthode

- Aucune question ci-dessus n'est marquée `COVERED` sur la seule base d'un proxy ambigu — quand
  le dénominateur ou la donnée exacte manquait (rang T1 en distribution, effets avant/après en
  graphique dédié), le statut est `PARTIAL` avec la limite explicitée, jamais surévalué.
- Les deux `PARTIAL` restants (distribution de rang T1, graphique avant/après) sont des questions
  dont la **donnée** est intégralement capturée en base (Phase 2) — la limite est uniquement
  l'absence d'une visualisation dédiée dans le dashboard actuel, par choix de périmètre (« ne
  refais pas le dashboard visuellement », consigne de la mission), pas un gap de télémétrie.
